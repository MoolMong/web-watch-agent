    감시 조건 설정

    조건을 바꾸고 이 조건으로 지금 검색을 누르면 바로 검색하고, 이후 3시간마다 그 조건으로 계속 감시합니다.

        알림 민감도란? 확인할 때마다 Jev가 "지금 사는 게 낫다"고 볼 확률을 0~100%로 냅니다(대시보드의 구매 확률). 이 확률이 고른 기준 이상이면 지금 구매 추천으로 바뀝니다. 기준을 낮추면 추천이 자주 뜨고, 높이면 확실할 때만 뜹니다. 목표가에 도달하면 이 기준과 상관없이 추천합니다.

        지금 검색은 이렇게 동작합니다. 버튼을 누르면 GitHub에 조건이 채워진 "검색 요청" 화면이 열립니다. Submit new issue만 누르면, 켜져 있는 PC가 2분 안에 새 조건을 저장하고 바로 검색한 뒤 이 화면을 갱신합니다. (공개 사이트에 쓰기 권한을 두지 않기 위해 GitHub 로그인으로 한 번 확인받는 방식입니다.)
